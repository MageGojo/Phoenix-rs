## 命令

```bash
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo fmt --all -- --check
```

应用侧常用：

```bash
cargo install px-cli     # crates.io；或 cargo install --path crates/phoenix-cli
# 开发本仓库时优先用本地 CLI：
#   cargo build -p px-cli --release && ./target/release/px …
px new my-app
px update                # 只刷新框架核心文件，不改业务代码
px make:model Post --all
px migrate
px dev
px release --version 0.1.0 --tarball
# release 二进制可从 staging/bin 直接启动；console 会 chdir 到 release 根
```

三模式 + SQLite + 框架能力双路径烟测（SPA / Islands / SSR / Notes / WS·SSE·JWT·Auth·Metrics·Storage·Queue·Mail·Plugin）：

```bash
cd examples/render-modes-smoke
cp .env.example .env && npm install   # RATE_LIMIT_REQUESTS≥300 便于脚本连打
../../target/release/px migrate
../../target/release/px dev
# 另开终端统一验收（开发态 / 产物同一脚本）：
./scripts/verify-features.sh
cargo run --quiet -- greet            # Plugin CLI → smoke-hello

../../target/release/px release --version 0.2.0 --tarball
STAGING=dist/releases/0.2.0/staging
mkdir -p "$STAGING/storage"           # 本地 staging 烟测；正式 install 链 shared/storage
(cd "$STAGING" && ./bin/phoenix-manage migrate)
(cd "$STAGING/bin" && ./render-modes-smoke serve)
./scripts/verify-features.sh
```

PASS 表与旁路示例（blog / multi-app；redis·PG·MySQL SKIP 条件）见：

- `examples/render-modes-smoke/docs/FEATURE_VERIFY.md`
- `examples/render-modes-smoke/docs/SIDE_EXAMPLES.md`

外部依赖与缺口能力（Docker 临时服务，端口避开本机其它栈）：

```bash
# Colima 未起时：colima start
./scripts/verify-external-features.sh
# 测完只删容器：
docker compose -f docker-compose.test-services.yml down -v
# 可选：colima stop
```

说明见 [`EXTERNAL_FEATURE_VERIFY.md`](EXTERNAL_FEATURE_VERIFY.md)。等价手动 env：

```bash
export PHOENIX_TEST_REDIS_URL=redis://127.0.0.1:16379/0
export PHOENIX_TEST_POSTGRES_URL=postgresql://phoenix:phoenix_test_password@127.0.0.1:15432/phoenix_test
export PHOENIX_TEST_MYSQL_URL=mysql://phoenix:phoenix_test_password@127.0.0.1:13306/phoenix_test
```

门面 lean / 按需能力：

```bash
cargo check -p phoenixrs --no-default-features
cargo check -p phoenixrs --no-default-features --features tls,websocket,sse,auth,jwt,password,metrics
```

品牌：**Phoenix-rs**；CLI 包 `px-cli`→`px`；门面包 `phoenixrs`（见 ADR-009）。  
前端 npm：`@apizero/react` / `@apizero/react-ssr` / `@apizero/vite`（见 `docs/RELEASE.md`「npm 发布名」）。  
`px dev`：Vite HMR + Rust 源码监听自动重启（见 `docs/DX.md`）。  
托管：GitHub + GitCode 双镜像（见 `docs/RELEASE.md` / README「源码镜像」）。

## 依赖约定

| 能力 | crate / 工具 |
| --- | --- |
| HTTP | Hyper 1.x + hyper-util |
| ORM | Toasty 0.8（sqlite / postgresql / mysql） |
| Redis | `redis`（tokio + connection-manager），原子操作用 Lua |
| WebSocket | `tokio-tungstenite` + Hyper `OnUpgrade`（首版仅 H1） |
| 队列 | `phoenix-queue`（Memory backend 首版） |
| 邮件 | `phoenix-mail`（MemoryTransport 首版，无内置 SMTP） |
| 应用 CLI | `phoenix-console`（`myapp <cmd>`，`commands!` 宏） |
| 前端 | Vite + React + TypeScript |
| 配置补全 | JSON Schema + Taplo / Even Better TOML（`schemas/`、`taplo.toml`） |
| Feature / 插件 | `phoenix-plugin`：`Plugin` + `FeatureSet`（见 FEATURES.md） |
| 发版流水线 | `phoenix-release` + `px release*`（见 RELEASE_PIPELINE.md） |
| 密钥扫描 | Gitleaks + `.gitleaks.toml` |
| 依赖策略 | `deny.toml` + cargo-deny |
