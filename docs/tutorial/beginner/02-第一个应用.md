# 02 · 第一个应用

← [01 环境与安装](./01-环境与安装.md) · 下一章 → [03 项目地图](./03-项目地图.md)

## 目标

创建应用、配置 `.env`、用 `px dev` 看到首页。

## 必做

### 1. 创建项目

在练习目录的**上一级**执行（不要在 Phoenix 框架仓库根里 `px new` 除非你清楚在做什么）：

```bash
px new learn-phoenix
cd learn-phoenix
cp .env.example .env
```

常用选项（本阶段可先默认）：

```bash
px new learn-phoenix --render-mode islands --database sqlite
# --render-mode spa|ssr
# --database sqlite|pgsql|mysql|all|none（视 px 版本选项为准）
```

若你用框架 path 依赖做贡献/联调：

```bash
px new learn-phoenix --framework-path /path/to/Phoenix
```

### 2. 看一眼环境变量

打开 `.env`，确认至少：

- `APP_ADDR` / `APP_URL`（默认 `127.0.0.1:3000`）
- `VITE_DEV_URL`（默认 Vite `5173`）

初级若项目带了 SQLite，可先 `px migrate`；若 `database=none`，跳过迁移。

### 3. 启动开发栈

```bash
px dev
```

浏览器打开 `APP_URL`（通常 http://127.0.0.1:3000 ）。  
`px dev` 会同时管 Rust 热重启与 Vite HMR；Ctrl-C 结束两者。

### 4. 停下来观察

终端应出现类似 “Phoenix application ready…”。改一行首页文案前，先完成下一章「项目地图」。

## 讲解

| 进程 | 职责 |
| --- | --- |
| Rust 应用 | 路由、Session/CSRF、页面协议、业务 |
| Vite | 开发期前端资源与 HMR |

生产环境不会跑 Vite；初级阶段只熟悉 `px dev`。

## 验收

- [ ] 浏览器能打开首页，标题或文案来自脚手架
- [ ] `Ctrl-C` 后端口释放，再次 `px dev` 仍正常

## 常见问题

- **端口占用**：改 `.env` 的 `APP_ADDR` / `APP_URL` / `VITE_DEV_URL`，三者一致。
- **依赖装不上**：在应用根再执行 `npm install`，检查网络与 Node 版本。
