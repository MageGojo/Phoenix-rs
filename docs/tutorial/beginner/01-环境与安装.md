# 01 · 环境与安装

← [00 怎么用这套教程](../00-怎么用这套教程.md) · 下一章 → [02 第一个应用](./02-第一个应用.md)

## 目标

装好 Rust、Node、`px`，并能看到 `px` 帮助信息。

## 必做

### 1. 检查 Rust / Node

```bash
rustc --version    # 需要 1.95+
cargo --version
node --version
npm --version
```

版本不够：按 [rustup](https://rustup.rs/) 升级 toolchain；Node 建议安装当前 LTS。

### 2. 安装 `px`

**日常推荐（crates.io）：**

```bash
cargo install px-cli
px --help
```

**跟本仓库源码开发时：**

```bash
cd /path/to/Phoenix
cargo build -p px-cli --release
./target/release/px --help
# 可选：cargo install --path crates/phoenix-cli
```

安装后命令名是 **`px`**（不是 `px-cli`）。门面包在 Cargo 里叫 `phoenixrs`，代码里仍写 `phoenix::…`。

### 3. 确认 PATH

```bash
which px
px list
```

若 `command not found`：把 `~/.cargo/bin` 加入 shell PATH 后重开终端。

## 讲解

- Phoenix-rs ≠ Elixir Phoenix；也不是 Laravel 移植，只是 DX 相近。
- 应用开发默认走 `px`，不要从零手建 `routes/` / `views/` 树。

## 验收

- [ ] `px --help` 能列出 `new` / `dev` / `make:*` / `release*`
- [ ] 已记下用的是 crates.io 的 `px` 还是仓库里的 `./target/release/px`
