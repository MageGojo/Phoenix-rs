# 03 · 项目地图

← [02 第一个应用](./02-第一个应用.md) · 下一章 → [04 页面与 Props](./04-页面与Props.md)

## 目标

建立目录心智模型：业务写哪里、生成物碰不得。

## 必做

在应用根执行，对照打开文件（只读）：

```bash
ls app routes views config src database 2>/dev/null
```

按下表在编辑器里各打开**一个**代表文件，标出「我以后会改 / 不会改」：

| 路径 | 职责 | 初级是否手改 |
| --- | --- | --- |
| `routes/*.rs` | 路由表，由 `mount_routes!` 挂载 | 改路由时改 |
| `app/controllers/` | 处理请求、返回 Page / JSON | 改 |
| `app/props/` | 页面 Props（Rust 契约） | 改 |
| `app/requests/` | 入参 DTO + 校验 | 改 |
| `app/resources/` | 出参资源形状 | 改 |
| `app/models/` | Toasty 模型（有 DB 时） | 中级再改 |
| `views/pages/` | React 页面 | 改 |
| `views/islands/` | 岛屿组件 | 改 |
| `views/generated/` | TS 契约与 routes | **禁止手改** |
| `config/*.toml` | 非密钥配置 | 改 |
| `.env` | 密钥与本机覆盖 | 改（勿提交密钥） |
| `database/migrations/` | 迁移 | 中级再改 |
| `src/main.rs` / `src/lib.rs` | 入口与 `application()` | 少改；中级注入 DB |

打开 `.phoenix`：记录 `render_mode`、`database`、`frontend`。

## 讲解

脚手架用 `<phoenix:…>` 标记托管区块：生成器只改标记内内容，标记外你的代码保留。  
同名目标默认拒绝覆盖，重建用 `--force`（慎用）。
