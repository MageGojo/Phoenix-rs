7. [ ] 有一份自己的生产配置清单  

## 端到端演示脚本（本地）

```bash
px release --version 0.2.0 --tarball
export PHOENIX_DEPLOY_ROOT=/tmp/learn-phoenix-deploy
px release:install --tarball dist/releases/0.2.0/*.tar.gz --version 0.2.0 \
  --restart-cmd 'echo restarted'
px release:status
px release:rollback --steps 1 --restart-cmd 'echo restarted'
```

## 口头题

1. 上传 tarball 是框架做还是运维做？  
2. 迁移失败为什么不能切 `current`？  
3. 为何回滚默认不 `migrate down`？

要点：1）运维/CI 上传；2）避免半新代码接流量；3）生产 schema 前向兼容，避免数据丢失。
