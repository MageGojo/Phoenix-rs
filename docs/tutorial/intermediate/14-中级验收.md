# 14 · 中级验收

← [13 Feature 与测试](./13-Feature与测试.md) · 下一章 → [15 发版流水线](../advanced/15-发版流水线.md)

## 必做清单

1. [ ] SQLite 已启用；`px migrate` / `px status` 正常  
2. [ ] 至少一种资源（Note/Post…）**真实**列表 + 创建  
3. [ ] 契约变更只改 Rust；generated 为生成结果  
4. [ ] 明确默认渲染模式；知道生产是否需要 Node renderer  
5. [ ] CSRF / Session / CSP 仍在  
6. [ ] 至少一条 `cargo test`（feature/unit）与业务相关且通过  

## 演示脚本（建议）

```bash
px migrate
px dev
# 浏览器 /notes → POST 创建 → 刷新可见
cargo test
```

## 口头题

1. `phoenix-manage` 在开发和发版中各干什么？  
2. 为什么 Islands 生产包通常还要准备 Node 依赖？  
3. `release:install` 还没学：你预期迁移失败时会不会切换 `current`？

要点：1）本地/制品内跑迁移；2）renderer.js 依赖 react 等且制品不含 node_modules；3）失败不切换（高级验证）。
