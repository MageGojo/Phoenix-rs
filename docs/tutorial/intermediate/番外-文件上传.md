# 番外 · 文件上传（选修）

前置：完成 [06 表单与校验](../beginner/06-表单与校验.md) 与 [08 启用 SQLite](./08-启用SQLite.md)。  
读完你能做出「选图 → 进度条 → 落盘 → 拿到 URL」的完整闭环。

## 目标

用 `Multipart<T>` + `phoenix-storage` + React `Form` 上传一张封面图。

## 必做

### 1. 服务端：接收并落盘

```rust
use phoenix_http::{Json, Multipart, MultipartData, Response, StatusCode};
use phoenix_storage::LocalDisk;
use serde_json::json;

fn cover_error(rule: &str, message: &str) -> Response {
    // 保持 { errors: { field: [{ rule, message }] } } 形状，前端 FieldError 才能自动回填
    (StatusCode::UNPROCESSABLE_ENTITY, Json(json!({
        "message": "The submitted data is invalid.",
        "errors": { "cover": [{ "rule": rule, "message": message }] },
    }))).into_response()
}

pub async fn store_cover(Multipart(data): Multipart<MultipartData>) -> Response {
    let Some(cover) = data.field("cover") else {
        return cover_error("required", "请选择封面图片");
    };
    // 服务端是最终校验者：大小与类型都要在这里查
    if cover.bytes().len() > 2 * 1024 * 1024 {
        return cover_error("max_size", "封面不能超过 2MB");
    }
    if !matches!(cover.content_type(), Some("image/png" | "image/jpeg" | "image/webp")) {
        return cover_error("mime", "封面必须是 PNG/JPEG/WebP");
    }

    let disk = LocalDisk::new("storage/app/public").expect("storage root");
    let key = format!("covers/{}.png", uuid_or_timestamp()); // key 由服务端生成，别用客户端文件名
    disk.store_bytes(&key, cover.bytes().clone()).await.expect("store cover");
    (StatusCode::CREATED, Json(json!({ "url": format!("/storage/{key}") }))).into_response()
}
```

（`uuid_or_timestamp()` 代指你自己的唯一 key 生成；返回类型/错误处理按你项目的控制器风格调整——对照 `examples/blog/app/controllers/mod.rs` 的 `(StatusCode, Json<T>)` 写法。）

### 2. 挂路由

```rust
.post("/api/posts/cover", AdminController::store_cover)
.name("posts.cover")
```

多 multipart 路由不用 `.action`（契约是 JSON 语义）；前端用 `createRustAction` 手动标注类型即可。

### 3. React：选图 + 进度条

```tsx
import { createRustAction, Form, FieldError } from "@apizero/react";

const storeCover = createRustAction<{ cover: File | null }, { url: string }>("posts.cover");

<Form action={storeCover} initialValues={{ cover: null }}>
  {(form) => (
    <>
      <input
        type="file"
        accept="image/*"
        onChange={(e) => form.setField("cover", e.target.files?.[0] ?? null)}
      />
      <FieldError errors={form.errors} name="cover" />
      {form.progress !== null && <progress value={form.progress} max={1} />}
      <button disabled={form.processing || !form.data.cover}>上传</button>
    </>
  )}
</Form>
```

`data` 里有 `File` 时 `Form` 自动切换为 multipart 提交（CSRF、422 回填、防重复提交与 JSON action 完全一致），`form.progress` 给进度条。

### 4. 故意触发 422

传一个 3MB 文件或非图片，确认错误出现在 `FieldError` 里而不是 500。

## 讲解

| 环节 | 谁负责 |
| --- | --- |
| 序列化（File→文件域、标量→文本域、嵌套→JSON） | `@apizero/react` 自动 |
| 进度 | XHR `upload.progress` → `form.progress` |
| 校验（大小/类型/必填） | **服务端**（前端 `accept` 只是体验） |
| 落盘与命名 | `phoenix-storage`，key 服务端生成 |

## 验收

- [ ] 上传成功拿到 URL，文件出现在 `storage/app/public/covers/`
- [ ] 超大/非图片文件返回 422 且 `FieldError` 显示中文提示
- [ ] 未关闭 CSRF；未信任客户端文件名
