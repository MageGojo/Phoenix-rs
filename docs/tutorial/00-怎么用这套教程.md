## 本教程解决什么

让你按固定顺序学会：建应用 → 写页面与表单 → SQLite 业务 → 打包装上线。  
不替代 API 参考手册；每章只覆盖「这一步必须懂的」。

## 学习节奏

| 规则 | 说明 |
| --- | --- |
| 一章一事 | 章节标题即本课唯一主题 |
| 先必做再延伸 | 「必做」不过关不进下一章 |
| 不横跳 | 不要同时改渲染模式、数据库和发版 |
| 记笔记 | 记下你的应用路径、端口、踩坑 |

## 推荐环境

- macOS / Linux（Windows 可用，发版软链行为以文档为准）
- Rust **1.95+**、Node.js（建议 LTS）、`cargo` / `npm`
- 初级可无数据库；中级起用 SQLite 文件库

## 术语速览（后面会展开）

| 词 | 含义 |
| --- | --- |
| `px` | 官方 CLI（包名 `px-cli`） |
| 契约 (contract) | Rust 为唯一来源，生成 TS 类型与 action |
| Page / Props | 控制器返回的页面数据，对应 `views/pages` |
| Resource 路由 | 一套 REST 风格命名路由 |
| 制品 / release | `px release` 打出的可部署包 |

## 必做

1. 打开 [README 学习路径](./README.md)，浏览三级目录，不要开始写代码。
2. 选定练习目录（例如 `~/Project/learn-phoenix`），记在笔记里。
3. 确认你会用终端执行 `cargo`、`node`、`npm`。
